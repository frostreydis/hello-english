# Інструкції для агентів

Прочитайте **README.md** у цій папці повністю, перш ніж щось змінювати. Там описано структуру, формат уроків, робочий цикл (розділ 4) і те, як додати урок (розділ 6) та виправити помилку (розділ 7).

Коротко: редагуйте тільки `src/` (папка `docs/` — зібраний сайт для GitHub Pages, вона генерується), після змін запускайте `node validate.mjs` і `node build.mjs`, нічого не встановлюйте, ідентифікатори уроків і ключ сховища `en-trainer-v1` не перейменовуйте.

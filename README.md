# Hello, English — англійська з нуля до B2

**Hello, English** — програма вивчення англійської з нуля до B2 для україномовних і тренажер, що працює в браузері як вебдодаток (PWA): сайт на GitHub Pages, прогрес — у localStorage браузера. Має **мій словник**: власні слова з перекладом, вимовою (американською й британською), транскрипцією, записами носіїв, тренуванням, а також **експортом та імпортом** (файл, таблиця, текст).
Це «брат» словацького тренажера [Ahoj, Slovensko](../slovak-trainer/README.md): той самий рушій, інший зміст і ключ сховища.
Цей README написано і для людини, і для **агента (Claude Code тощо)**: тут є все, щоб доповнювати тренажер і виправляти помилки з іншої сесії.

## 1. Як користуватися

1. Відкрийте сайт тренажера в **Chrome** або **Edge** (адреса на GitHub Pages: `https://<нік>.github.io/hello-english/`, див. розділ 9) і **встановіть його як додаток**:
   - **Android**: меню ⋮ → «Додати на головний екран» → «Установити»;
   - **комп'ютер**: значок «Установити» праворуч в адресному рядку (або в меню ⋮);
   - **iPhone / iPad**: «Поділитися» → «На екран „Додому“».
   Тренажер також підкаже це на вкладці «Сьогодні» і в ⚙️ «Налаштування». Встановлений додаток відкривається в окремому вікні й працює без інтернету, а браузер надійніше зберігає його дані.
2. Англійською говорить англійський голос:
   - **голос системи** (є майже всюди): в Edge це *Microsoft Aria / Jenny / Guy (US) і Sonia / Ryan (UK) Online (Natural)*, у Chrome — *Google US English / Google UK English*, на Mac і iPhone — *Samantha, Daniel* тощо;
   - якщо голосу потрібного акценту в системі немає — **онлайн-голос Google** (потрібен інтернет).
   В ⚙️ «Налаштування» можна вибрати **акцент** (американська US чи британська UK вимова), конкретний голос і швидкість.
3. Почніть із вкладки «Сьогодні»: там план на день, поточний урок і таймер.
4. Прогрес зберігається в браузері на цьому пристрої. Кожен пристрій і кожен браузер має свій окремий прогрес. **Мій словник** можна перенести на інший пристрій експортом та імпортом (розділ 1.1); прогрес уроків — ні (свідоме рішення: без сервера).

### 1.1 Мій словник (`📒 Словник`)

- **Додати слово**: англійське слово чи фраза + переклад; за бажанням — примітка (частина мови, контекст), приклад речення, транскрипція.
- **Послухати**: 🔊 — вибраним акцентом, 🐢 — повільно, US / UK — іншим акцентом, 🎙️ — **запис живої людини** (якщо він є у словниковій базі), 📖 — сторінка слова в Cambridge Dictionary, ▶ YouGlish — слово у відео з реальними людьми.
- **Транскрипція й записи носіїв** шукаються в безкоштовному словниковому сервісі [dictionaryapi.dev](https://dictionaryapi.dev) (дані Wiktionary): автоматично після додавання слова (можна вимкнути в налаштуваннях), кнопкою «🔎» біля слова або для всіх слів без транскрипції одразу (кнопка «🔎 Транскрипція (N)» угорі словника — зручно після імпорту). Сервісу надсилається лише саме англійське слово. Для фраз записів зазвичай немає — тоді звучить синтезований голос.
- **Повторення**: слова словника потрапляють у вкладку «Слова» (інтервальне повторення, разом зі словами уроків); кнопка «🃏 Повторити мої слова» — лише слова словника.
- **Тренування**: 10 завдань зі слів словника — диктант (почути й написати), переклад українська → англійська, вибір перекладу.
- **Редагування й видалення**: ✎ і ✕ біля слова. Якщо змінити англійське слово, прогрес його повторення переноситься.

### 1.2 Експорт та імпорт словника (`📒 Словник → ⇅ Імпорт / експорт`)

| Що | Навіщо | Формат |
|---|---|---|
| ⬇️ **Файл словника (.json)** | резервна копія; перенесення на телефон, інший браузер чи комп'ютер | усі поля слова + (за бажанням) прогрес повторення |
| 📤 **Поділитися файлом** (телефон) | надіслати файл собі в Telegram / пошту й відкрити на іншому пристрої | той самий .json |
| ⬇️ **Таблиця (.csv)** | Excel, Google Таблиці, Anki, Quizlet | `english,ukrainian,note,example,ipa`, UTF-8 |
| 📋 **Копіювати як таблицю** | вставити в Google Таблиці / Excel / нотатки | рядки з табуляцією |

**Імпорт** приймає: файл `.json` цього тренажера; `.csv` / `.tsv` / `.txt` (роздільник — табуляція, `;` або `,`; заголовок необов'язковий); або **вставлений текст**, по слову на рядок: `apple — яблуко`, `apple - яблуко`, `apple; яблуко`, `apple = яблуко`, `apple<TAB>яблуко` (так копіюються клітинки з Excel / Google Таблиць, Anki, Quizlet).

Перед імпортом показується перегляд: скільки слів нових, скільки вже є, скільки з іншим перекладом і які рядки не розпізнано. Для слів з іншим перекладом можна: залишити мій переклад / замінити / об'єднати («квартира; помешкання»). Порожні примітки, приклади й транскрипції заповнюються з файлу. Прогрес повторення з файлу береться лише для слів, яких у вас ще немає (або які ви ще не повторювали). Одразу після імпорту можна натиснути **«↩ Скасувати імпорт»**.

Однакові слова визначаються за англійським написанням без урахування регістру й зайвих пробілів (`Apple` = `apple`).

### Надійність збереження

- Прогрес лежить у localStorage сайту під ключем `en-trainer-v1` і записується після кожної дії. Ключ відрізняється від словацького тренажера (`sk-trainer-v1`), тож обидва тренажери можуть жити на одному акаунті GitHub Pages.
- **Постійне сховище.** Під час запуску тренажер просить у браузера постійне сховище (`navigator.storage.persist()`). Тоді браузер не видаляє дані сайту сам, навіть коли на пристрої мало місця. Стан видно в ⚙️ «Налаштування» → «Збереження прогресу».
- **Кілька вкладок або вкладка + встановлений додаток** не затирають прогрес одне одного: зміна в одній вкладці перечитується в інших.
- **Якщо запис не вдався** (немає місця, заблоковано дані сайтів), з'являється попередження, а подробиці — в налаштуваннях.
- **Прогрес зникне**, якщо в браузері очистити «Файли cookie та інші дані сайтів» для цього сайту. **Регулярно експортуйте словник** — це єдині дані, які шкода втратити найбільше.
- **Офлайн і оновлення.** Після першого відкриття тренажер працює без інтернету (крім онлайн-голосу, пошуку транскрипції й записів носіїв). Нову версію браузер бере з мережі під час наступного відкриття; у вже відкритому вікні з'явиться «🔄 Вийшла нова версія → Оновити». Прогрес оновлення не зачіпає.

### Прогрес, пропуски і «почати наново»

- **Що зберігається:** стан кожного уроку (теорія, вправи ≥ 80%, розмова, місія), **незавершений підхід до вправ** (можна закрити й продовжити з того самого завдання), пропущені уроки, повторення слів, мій словник, дні занять і серія. Підсумок — у ⚙️ «Налаштування» → «Збереження прогресу».
- **Пропустити завдання:** «Пропустити ⏭» показує правильну відповідь і переходить далі; пропущене рахується як невиконане.
- **Пропустити урок:** у шапці уроку «⏭ Пропустити урок» (на телефоні — у «⋯ Керування уроком»). «↩ Повернути урок» скасовує пропуск.
- **Почати з певного уроку:** «▶ Почати з цього уроку» позначає всі попередні незавершені уроки як пропущені (зручно, якщо ви вже знаєте рівень A1).
- **Пройти урок наново:** «↺ Пройти урок наново» скидає позначки і вправи уроку; слова лишаються в повторенні.
- **Почати все спочатку:** ⚙️ «Налаштування» → «Скинути уроки», «Скинути повторення слів» або «Почати навчання з нуля». Мій словник і налаштування голосу при цьому **не видаляються**; словник очищається лише окремою кнопкою в самому словнику.

### Як перевіряються відповіді

- Регістр і розділові знаки не важливі; дефіс = пробіл (`twenty-five` = `twenty five`).
- **Скорочення рівнозначні повним формам**: `I'm` = `I am`, `don't` = `do not`, `can't` = `cannot`, `she's` = `she is` / `she has`, `I'd` = `I would` / `I had`.
- **Британський і американський правопис** зараховуються однаково: `colour` = `color`, `organise` = `organize`, `travelling` = `traveling`, `centre` = `center`, `grey` = `gray`.
- **Одна описка** в довгому слові (`beatiful`) — «🟡 Майже»: зараховується, якщо в налаштуваннях не ввімкнено суворий режим. Описку в закінченні (`work` замість `works`) тренажер вважає граматичною помилкою.

## 2. Для кого тренажер (для рішень щодо змісту)

| | |
|---|---|
| Мовна база | українська (часто й російська); інколи словацька чи інша слов'янська |
| Де | у Словаччині чи іншій неангломовній країні: англійська — на роботі, в подорожах, у фільмах, з іноземцями |
| Мета | спілкування, робота в міжнародній команді (зустрічі, листи, дзвінки), подорожі, фільми й новини; цільовий рівень **B2**, без поспіху |
| Час | **15–30 хв у робочі дні**, вихідні вільні |
| Формат | самостійно; телефон і комп'ютер |
| Пріоритет навичок | розмова → слухання → читання → письмо |

```

├─ validate.mjs            ← перевіряє дані уроків, генератори й перевірку відповідей

   └─ data/
```

Технології: чистий JavaScript без залежностей і без фреймворків. Маршрутизація — через `#/...`. Глобальний простір імен — `window.EN`.
Тренажер працює лише через `https://` (GitHub Pages) або `http://127.0.0.1` / `localhost` під час розробки: service worker, буфер обміну й мікрофон потребують безпечного контексту. Відкриття з `file://` не підтримується.
Service worker реєструється лише в зібраній версії (`docs/`, де є `EN.BUILD`). У `src/` його немає, тож правки видно одразу, без кешу.

## 4. Робочий цикл агента (обов'язково)

1. **Редагуйте тільки `src/`** (і за потреби `tools/`, `build.mjs`, `validate.mjs`). Папка `docs/` генерується, але її теж комітять: GitHub Pages віддає сайт саме з неї.
2. Після змін виконайте:
   ```
   node validate.mjs                        # усі дані уроків: структура, дублікати, [[ ]], відповіді, генератори
   node validate.mjs data/lessons-a2a.js    # лише один файл уроків
   node build.mjs                           # збирає docs/ і друкує версію збірки
   ```
   Для коду ще: `node --check src/<файл>.js`.
3. Перевірте в браузері: `python -m http.server 8000 -d docs` і відкрийте `http://127.0.0.1:8000/`, F12 → Console, вставте вміст `tools/selftest-console.js`. Очікуваний результат — «✅ Усе гаразд». Прогрес і словник на цій адресі скрипт відновлює сам. Для розробки без кешу: `python -m http.server 8000 -d src`.
   Якщо зібрана версія показує старий вміст: F12 → Application → Service workers → Unregister (або «Update on reload»).
4. **Нічого не встановлюйте** (npm-пакети, бібліотеки тощо): проєкт навмисно без залежностей. Потрібні лише `node` і за бажанням `python`.
5. Додайте рядок у «Журнал змін» унизу цього файлу.

## 5. Формат уроку (`src/data/lessons-*.js`)

```js
window.EN = window.EN || {};
EN.lessons = EN.lessons || [];
EN.lessons.push({
  id: 'a2-1',               // унікальний, НЕ змінювати після публікації (від нього залежить прогрес); починається з id етапу
  stage: 'a2',              // id етапу з program.js: a0 | a1 | a2 | b1 | b2
  num: 'A2.1',              // номер для показу
  title: 'Past Continuous — що відбувалося в певний момент',
  dur: '2 тижні',           // a0: '2 дні', a1: '1 тиждень', a2 і b1: '2 тижні', b2: '3 тижні'
  goals: ['…', '…'],        // 2–4 пункти «після уроку я вмію…»
  theory: `HTML-рядок`,     // див. розмітку нижче
  vocab: [['word', 'переклад', 'примітка (необов\'язково)'], …],
  ex: [ …вправи… ],
  say: [['English phrase.', 'Переклад.'], …],    // фрази для shadowing (запис голосу)
  speak: ['Завдання для говоріння вголос', …],
  mission: 'Завдання в реальному житті'
});
```

Зразок — урок `a1-1` у `src/data/lessons-a1a.js`.

### Розмітка в `theory`, `mission`, поясненнях `e`

- `[[текст]]` — клікабельний англійський фрагмент з озвученням; `[[показати|що озвучити]]` — якщо озвучувати треба інше. **Усередині `[[ ]]` — лише англійська** (кирилицю англійський голос не прочитає; validate.mjs це перевіряє).
- Звичайний HTML: `<h3>`, `<p>`, `<b>`, `<i>`, `<ul>`, таблиці всередині `<div class="tblwrap"><table>…</table></div>`.
- Блоки-виноски: `<div class="tip">` (порада, вимова), `<div class="note">` (⚠️ пастка, відмінність від української), `<div class="good">` (добра новина / подібність з українською).
- Транскрипцію пишіть у квадратних дужках IPA: `[θ]`, `/ˈwɔːtə/`. Кириличні «підказки» вимови — лише як приблизні й з позначкою «≈».
- Не вживайте рядок `</script` — збирання впаде.

### Типи вправ (`ex`)

| `t` | Що це | Поля | Правила |
|---|---|---|---|
| `c` | вибір | `q`, `o: [правильний, хибний, хибний]`, `e?`, `exact?` | **`o[0]` — правильний** (порядок перемішується автоматично). Хибні варіанти мають бути *однозначно* хибними в стандартній англійській. Варіанти не повинні збігатися з правильним після нормалізації (регістр, скорочення, US/UK); якщо різниця навмисна (`Yes, she is.` / `Yes, she's.`), додайте `exact: true`. |
| `i` | введення | `q`, `a: 'відповідь'` або `['варіант1','варіант2']`, `e?`, `exact?` | Відповідь англійською. Регістр, розділові знаки, скорочення (`I'm` = `I am`) і правопис US/UK ігноруються автоматично — не дублюйте їх в `a`, але **додавайте всі інші природні варіанти**. `exact: true` — для вправ саме на скорочення чи правопис: тоді `I am` ≠ `I'm` і описки не прощаються. |
| `o` | порядок слів | `q` (переклад українською), `a: 'Sentence.'` або масив альтернатив | Слова беруться з першого варіанта (розбивка за пробілами, розділові знаки лишаються при словах). Альтернативи мають складатися з тих самих слів — це перевіряє `validate.mjs`. Додавайте всі природні варіанти порядку (`Yesterday I worked.` / `I worked yesterday.`). |
| `l` | диктант (озвучення) | `a: 'текст'`, `tr: 'переклад'` | Текст озвучує англійський голос, користувач його записує. 3–10 слів. |
| `g` | генерована вправа | `g: 'назва'`, `min?`, `max?` | Під час запуску `gen.js` перетворює її на `l` або `i` з новими випадковими даними. Генератори: `numListen` (число на слух → цифрами), `teenListen` (13 чи 30), `priceListen` (ціна в £ / $ / €), `timeListen`, `dateListen`, `yearListen`, `phoneListen` (номер телефону), `spellListen` (слово по буквах), `numWords` (число → словами), `timeWords`, `dateWords`. |

`e` — пояснення після відповіді (з розміткою `[[ ]]`).

Згенеровані вправи можуть мати службові поля (це не для ручних даних): `say` (що озвучити замість `a`), `check(v)` (власна перевірка, яка повертає `'ok'`/`'bad'`), `nodia` (цифрова клавіатура на телефоні), `ph` (підказка в полі), `h` (заголовок диктанту).
Новий генератор додається в `G` у `gen.js`. Його відповідь має проходити власну перевірку (`validate.mjs` проганяє кожен генератор 300 разів), а сам генератор треба додати в `DRILLS` у `views2.js`, якщо він потрібен у тренажері чисел.

### Модель стану (localStorage, ключ `en-trainer-v1`)

```js
EN.S = {
  v: 1,                                                 // версія схеми стану (core.js → VERSION)
  settings: { accent, voice, rate, strict, newPerDay, dir, autoIpa },
     // accent: 'us' | 'gb'; voice: '' — автоматично, '@online' — онлайн-голос Google, інакше ім'я голосу системи;
     // dir: 'mix' | 'en' (англ. → укр.) | 'uk'; autoIpa — шукати транскрипцію після додавання слова
  lessons: { '<id уроку>': { opened, theory, ex: { best, done }, speak, mission, skipped,
                             run: { n, q: [[індекс вправи, повтор?], …], pos, ft: {індекс: правильно?}, sk: {індекс: пропущено} } } },
  modules: { '<id модуля>': true },          // ручні позначки модулів (зараз усі етапи мають уроки)
  cards:   { '<lessonId|слово>': { due, int, ease, reps, lapses } },   // картки словника: 'my|слово'
  dict:    [{ en, uk, note?, ex?, ipa?, au?: { us?, gb?, au? }, added? }],   // мій словник; au — адреси записів носіїв
  days: { '<номер дня>': { ex, cards, speak } },  newDay: { day, count },
  ui:      { installTip, dictSort }          // dictSort: 'new' | 'az' | 'due'
}
```

- Під час читання (`core.js` → `load`) стан проходить `migrate` (кроки `MIGRATIONS`), зливається з `DEFAULTS` (нові поля отримують значення за замовчуванням, ключі `__proto__` / `constructor` / `prototype` відкидаються) і `tidy` (налаштування приводяться до чисел і відомих значень, записи словника — через `EN.cleanWord`: рядки обрізаються, дублікати відкидаються, адреси записів носіїв приймаються лише з `api.dictionaryapi.dev`, `ssl.gstatic.com`, `upload.wikimedia.org`).
- Якщо збережений запис не вдалося розібрати, його копія лишається під ключем `en-trainer-v1-broken`, а тренажер стартує з чистого стану. Якщо запис зроблено новішою версією (`v` більше за `VERSION`), тренажер нічого не записує, доки сторінку не оновлять.
- Стан сховища — `EN.store` (`newer`, `broken`, `failed`), постійне сховище — `EN.Storage.persisted`, встановлення — `EN.Install`, `EN.isInstalled()`.
- Урок «закритий» (`EN.lessonClosed`), якщо пройдений (`ex.done`) або пропущений (`skipped`). Поточний урок — перший не закритий (`EN.currentLesson`).
- Функції керування — у `core.js`: `skipLesson`, `resetLesson`, `startFrom`, `resetLessons`, `resetWords`, `resetState`; словника — у `dict.js` (`EN.Dict`).
- `run` зберігається, лише поки підхід не завершено. Якщо кількість вправ уроку змінилася (`run.n`), збережений підхід ігнорується.

### Формат файлу експорту словника

```json
{
  "format": "hello-english-dictionary",
  "version": 1,
  "app": "Hello, English",
  "exported": "2026-11-08T10:00:00.000Z",
  "count": 1,
  "words": [
    { "en": "reschedule", "uk": "перенести (зустріч)", "note": "verb", "ex": "Can we reschedule the call?",
      "ipa": "/ˌriːˈskedʒuːl/", "au": { "us": "https://api.dictionaryapi.dev/media/pronunciations/en/…-us.mp3" },
      "added": "2026-11-08", "card": { "due": 20400, "int": 4, "ease": 2.5, "reps": 2, "lapses": 0 } }
  ]
}
```

`card.due` — номер дня від 1970-01-01 за місцевим часом (як `EN.today()`), тож прогрес переноситься між пристроями. Імпорт також приймає масив `[{en, uk}]` чи `[[en, uk]]` і об'єкти з полями `english`/`word`/`term`/`front` і `ukrainian`/`translation`/`back`.

### Сумісність прогресу — важливо

- **Не перейменовуйте** `id` уроків: від них залежить, чи урок пройдено.
- Ідентифікатор картки слова — `lessonId|англійське_слово` (для словника — `my|слово`). Слово, що є в кількох уроках, має одну картку — з id **першого** уроку, де воно з'являється (`core.js` → `firstLesson`); `validate.mjs` показує такі повтори окремим рядком. Якщо змінити текст `vocab[i][0]`, прогрес повторення цього слова скинеться. Виправляти помилки можна й треба — просто майте це на увазі.
- **Ключ сховища `en-trainer-v1` не змінюйте** (навіть коли змінюється формат стану): інакше збережений прогрес не відкриється.
- Змінюєте формат стану — підніміть `VERSION` у `core.js` і додайте крок `MIGRATIONS[стара_версія] = (s) => { … }`. Нові поля з розумним значенням за замовчуванням міграції не потребують — досить додати їх у `DEFAULTS`.
- Змінюєте формат файлу експорту — підніміть `version` у `dict.js` і зберігайте вміння читати старі файли.

## 6. Як додати чи переписати урок

1. Допишіть урок у файл етапу в форматі з розділу 5 (або створіть новий файл і підключіть його в `src/index.html` після інших `lessons-*.js` і **перед** `reference.js`). Порядок файлів = порядок уроків у тренажері.
2. Обсяг уроку:
   - **етап 0**: теорія з таблицями звуків і прикладами, 12–20 слів, 10–14 вправ, 4–6 фраз;
   - **A1**: 15–25 слів, 12–15 вправ;
   - **A2–B2**: 15–25 слів, 13–18 вправ (уроки тривають 2–3 тижні).
   Завжди: мікс усіх 4 типів вправ, **щонайменше 2 диктанти** (`l`), 2–4 вправи «порядок слів» (`o`), 4–6 фраз для shadowing, 1–2 завдання для говоріння, 1 місія в реальному житті.
3. Теорія: граматичне правило з термінами, таблиця форм, багато озвучених прикладів `[[ ]]`, блоки `note` про відмінності від української (артиклі, порядок слів, часи, «двійне заперечення», допоміжні дієслова), `tip` про вимову нових слів, US / UK відмінності, де вони є.
4. Місії — реальні дії: написати повідомлення колезі англійською, переглянути відео й переказати, змінити мову телефона, поговорити з іноземцем, записати голосове.
5. `node validate.mjs data/<файл>.js` → `node validate.mjs` → `node build.mjs` → самоперевірка в браузері.

Приклад запиту до агента в новій сесії:
> «Відкрий папку english-trainer, прочитай README.md і допиши в урок B1.3 ще чотири вправи на пасив за правилами з розділу 6.»

## 7. Як виправити помилку

| Що не так | Де шукати |
|---|---|
| Помилка в англійському слові, перекладі, правилі | `src/data/lessons-*.js` або `reference.js` |
| Вправа зараховує неправильну або не зараховує правильну відповідь | поле `a` (додайте альтернативу) або `o` (для `c` перший варіант — правильний); для вправ на скорочення — `exact: true` |
| Не працює екран або кнопка | `views.js` / `views2.js` / `dictview.js`; помилка рендерингу показується на екрані (блок «Щось пішло не так» зі стеком) і в консолі |
| Логіка перевірки відповідей, скорочення, US/UK, описки | `core.js` → `EN.check`, `EN.norm`, `spelling`, `variants`, `oneTypo`; самоперевірки — у `validate.mjs` (масив тестів `EN.check`) |
| Інтервали повторення слів | `core.js` → `EN.srsGrade`, `EN.srsQueue` |
| Пропуск, продовження підходу, «пройти наново» | `exercises.js` → `run`/`save`/`record`; `core.js` → `skipLesson`, `resetLesson`, `startFrom`; кнопки — `views.js` → `lessonControls` |
| Неправильна форма числа, часу, дати, року; тренажер не приймає правильну відповідь | `gen.js` → `words`, `ordinal`, `yearWords`, `timeVariants`, `wnorm` і функції `check`; еталонні форми — у `validate.mjs` |
| Мій словник: додавання, транскрипція, записи носіїв | `dict.js` → `EN.Dict.add`, `update`, `lookup`, `parseLookup`, `enrichAll`; екран — `dictview.js` |
| Імпорт не розпізнає файл чи текст; експорт | `dict.js` → `parseText`, `parseCsv`, `parseJson`, `plan`, `apply`, `toJson`, `toCsv`, `toTsv` |
| Немає озвучення або голос не того акценту | `core.js` → `EN.TTS`. Голоси системи фільтруються за `lang` `en-*` і сортуються за якістю (Natural / Google / Premium); акцент — `accentOf`. Якщо голосу акценту немає або вибрано `'@online'`, говорить онлайн-голос Google (`ONLINE_URLS`, `tl=en-US` / `en-GB`). Перевірте в консолі: `EN.TTS.voices`, `EN.TTS.label()`, `speechSynthesis.getVoices().filter(v => v.lang.startsWith('en'))`. |
| Не пишеться голос | `core.js` → `EN.Rec`; потрібен дозвіл на мікрофон і `https://` |
| Прогрес не зберігається, зник або «двоїться» між вкладками | `core.js` → `load`, `EN.save`, `EN.store`, подія `storage`; перемальовування — `views2.js` → `EN.onExternalChange` |
| Після публікації телефон показує старі уроки | `src/sw.js` (сторінка — спершу з мережі), версія збірки — `build.mjs`; банер оновлення — `views2.js` → `registerWorker`, `showUpdateBar` |
| Іконки, назва чи кольори встановленого додатка | `src/manifest.webmanifest`; іконки малює `tools/icons.mjs` з прапора в `src/index.html` |
| Вигляд, мобільна версія | `styles.css` (брейкпоінт 700px; `@media (pointer:coarse)` — сенсорні екрани) |
| Вкладки в шапці не вміщаються або обрізаються | `views2.js` → `fitNav`: вимірює навігацію і вмикає компактні вкладки (`header.nav-compact`), а якщо й їм тісно — ховає назву біля прапора (`header.nav-tight`); стилі — `styles.css` |

Правило якості англійської: сумнівні форми, вимову й уживання перевіряйте в **Cambridge Dictionary** (https://dictionary.cambridge.org) чи **Oxford Learner's Dictionaries** (https://www.oxfordlearnersdictionaries.com); вживання фраз — у YouGlish. Не діліться прогресом користувача (localStorage) без потреби.

## 9. Публікація на GitHub Pages

1. Репозиторій — **публічний** (безкоштовний GitHub Pages працює лише з публічних репозиторіїв). Перед першим комітом увімкніть приховування пошти: GitHub → Settings → Emails → «Keep my email addresses private» і в цій папці виконайте `git config user.email "<id>+<нік>@users.noreply.github.com"`.
2. Створіть публічний репозиторій **`hello-english`** (опис, наприклад: «Тренажер англійської для україномовних: з нуля до B2, офлайн, PWA»; теги `english`, `ukrainian`, `language-learning`, `pwa`). Закомітьте все разом із `docs/` і відправте в гілку `main`.
3. GitHub → репозиторій → Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main**, папка **/docs** → Save. Через хвилину-дві сайт буде на `https://<нік>.github.io/hello-english/`.
4. Кожне оновлення: правки в `src/` → `node validate.mjs` → `node build.mjs` → самоперевірка → коміт `src/` **і** `docs/` → push.

Що варто знати:
- Усі сайти GitHub Pages одного акаунта (`https://<нік>.github.io/…`) мають **спільний localStorage**. Ключі тренажерів (`en-trainer-v1`, `sk-trainer-v1`) різні, кеші service worker теж (`en-trainer-…`, `sk-trainer-…`), тож вони не заважають одне одному.
- Онлайн-голос — неофіційний сервіс Google (`translate_tts`), без ключа й без гарантій. Транскрипція й записи носіїв — безкоштовний сервіс dictionaryapi.dev (дані Wiktionary, записи — Wikimedia Commons під ліцензіями CC BY-SA). Обидва можуть змінитися чи зникнути; тоді працює голос системи. Запити йдуть із браузера учня, і їм надсилається лише англійський текст.
- У репозиторії немає секретів і особистих даних; прогрес і словники учнів у репозиторій не потрапляють (`.gitignore` пропускає файли експорту `hello-english-dictionary-*`).
